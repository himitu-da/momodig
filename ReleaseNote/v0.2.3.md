# Release Note v0.2.3

## 変更点
- 地形生成ロジックを修正し、特定の条件下でボクセルが生成されないように変更しました。
    - TopDownモードでは、Y軸の絶対値が0.5を超えるボクセルは生成されません。
    - SideScrollerモードでは、Z軸の絶対値が0.5を超えるボクセルは生成されません。

## スクリプト実装概要

### `CubeTopDownPlacer.cs`
- `Generate`メソッド内で、ボクセルパターンの生成時にY座標をチェックし、条件を満たさないボクセルをパターンから除外するようにしました。

### `CubeSideScrollerPlacer.cs`
- `Generate`メソッド内で、ボクセルパターンの生成時にZ座標をチェックし、条件を満たさないボクセルをパターンから除外するようにしました。

### `VoxelChunk.cs`
- `Initialize`メソッドを修正し、`BaseCubePlacer`から渡された`pattern`配列を正しく解釈して`voxelTypes`に反映するようにしました。これにより、意図的に空気に設定されたボクセルが固体で上書きされる問題が解決されました。
- 掘削の判定ロジックを、ボクセルの中心点ではなく、掘削範囲とボクセルの重なり具合（重複率）で判定するように変更しました。
    - `VoxelChunk`に`diggingThreshold`変数を追加し、掘削に必要となる重複率をインスペクターから調整可能にしました。
