# Release Note v0.2.4

## 変更点
- **トロッコシステム（Minecart System）の実装**
  - 資源（石、鉄、金、ダイヤモンド）をトロッコで運搬できるシステムを追加しました。
  - トロッコの積載管理、送信クールタイム、複数台トロッコの管理機能を実装しました。
  - 掘削可否をトロッコの利用状況に連動させる仕組みを追加しました。

- **カメラ追従システム（Camera Follow System）の実装**
  - プレイヤーにカメラが追従する機能を追加しました。
  - TopDownモードとSideScrollerモードに応じて適切なカメラ位置・角度を自動調整します。
  - スムーズなカメラ移動と物理演算との同期を実現しました。

- **プレイヤーコントローラー（PlayerController）の改良**
  - プレイヤーの初期向きを移動モードに応じて適切に設定するように変更しました。
  - DiggingAreaのDiggerコンポーネントの取得・設定ロジックを改善しました。
  - インスペクターでの値変更に対応するOnValidate()メソッドを追加しました。
  - 回転計算ロジックを改良し、より自然なプレイヤーの向き変更を実現しました。

## スクリプト実装概要

### 新規追加スクリプト

#### `MinecartManager.cs`
- **ResourceType enum**: 資源の種類（石、鉄、金、ダイヤモンド）を定義
- **Minecart クラス**: 
  - 資源辞書と送信時間を管理
  - 各資源タイプの積載量を個別に追跡
- **MinecartManager クラス**:
  - `CartCapacity`: トロッコの積載容量
  - `cartunit`: トロッコの台数
  - `cartcooltime`: トロッコの送信クールタイム
  - `digable`: 現在掘削可能かどうかのフラグ
  - トロッコのクールタイム管理と自動的な利用可能トロッコの切り替え機能

#### `CameraFollowController.cs`
- **カメラ追従機能**: プレイヤーの移動に合わせてMainCameraが追従
- **移動モード対応**:
  - SideScrollerモード: サイドビュー用のカメラ位置・角度
  - TopDownモード: 俯瞰視点用のカメラ位置・角度
- **設定可能パラメータ**:
  - `followSpeed`: 追従速度
  - `useSmoothDamp`: スムーズな移動の有効/無効
  - モード別のオフセット設定
  - モード別の画角設定
- **FixedUpdate()使用**: 物理演算との同期でカメラのガタつきを防止

### 変更されたスクリプト

#### `PlayerController.cs`
- **初期設定の改良**:
  - 移動モードに応じた初期向きの設定
  - DiggingAreaの自動検出・設定機能を追加
- **回転ロジックの改良**:
  - TopDownモードでの回転計算を改善
  - SideScrollerモードでのより自然な回転
- **インスペクター対応**:
  - OnValidate()メソッドでエディタ時の値変更に対応
  - より直感的なインスペクター表示のためのHeader属性追加
- **参照管理の改善**:
  - ScoreTextの安全な取得
  - Diggerコンポーネントの自動設定

## 技術的詳細

### トロッコシステムの仕組み
- 複数のトロッコを管理し、使用中のトロッコが送信クールタイム中は自動的に利用可能な別のトロッコに切り替えます。
- `time`プロパティでトロッコの送信状態を管理し、0以下になると再利用可能になります。
- 掘削可能性(`digable`)をトロッコの利用状況と連動させ、全トロッコが使用中の場合は掘削を一時停止します。

### カメラシステムの特徴
- FixedUpdate()を使用して物理演算フレームと同期し、カメラのガタつきを防止します。
- 移動モードの変更を自動検出し、適切なカメラ設定に即座に切り替わります。
- オブジェクト参照の検証機能により、設定不備による実行時エラーを防止します。

## 注意事項
- トロッコシステムを利用する場合、適切な`DeltaTime`の設定が必要です。
- カメラ追従機能を使用する場合、MainCameraとPlayerオブジェクトの参照設定が必要です。
