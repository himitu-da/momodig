# Release Note v0.2.0

## 追加機能

### ゲームシステムの主要コンポーネント実装

- **PlayerController**: プレイヤーの入力、移動（水平・垂直モード）、向きの制御、スコア管理機能を実装しました。
- **Digger**: マウスクリックによる地形掘削機能を実装しました。掘削範囲はプレイヤーに追従します。
- **VoxelChunk**: ボクセルデータの管理、動的なメッシュ生成（隠面消去最適化を含む）、ボクセル破壊とアイテムドロップ機能を実装しました。
- **BaseCubePlacer**: 地形チャンクをシーンに配置するための基底クラスを実装しました。

## 変更点

- ゲームのコアとなる掘削とアイテム収集のサイクルを実装しました。
- Unityの新しいInput Systemに対応しました。

## 既知の問題

- 特になし。
