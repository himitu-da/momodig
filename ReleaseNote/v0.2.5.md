# Release Note v0.2.5

## 新機能
- **MiningScene（マイニングシーン）の追加**
  - 新しいゲームシーン「MiningScene.unity」を作成しました。
  - カメラ追従システム、ライティング、UI Canvasを含む完全なゲーム環境を構築しました。

- **ボクセルテクスチャ抽出システムの実装**
  - ボクセル破壊時に面テクスチャ情報を抽出する機能を追加しました。
  - `VoxelFaceTextureInfo`構造体による詳細な面テクスチャ管理を実装しました。

- **物理マテリアルシステムの強化**
  - プレイヤー用物理マテリアル「PlayerPhysics」を追加しました。
  - ボクセル用物理マテリアル「VoxelPhysics」を新規作成しました。

## 変更点
- **VoxelChunkの大幅な機能拡張**
  - テクスチャを含む完全な初期化メソッドを追加しました。
  - ボクセル面のテクスチャ情報取得機能を実装しました。
  - アイテムドロップ時にボクセル座標情報を含むように改良しました。

- **CubeSideScrollerPlacerの配置ロジック改善**
  - Z軸の境界判定をより正確にするため、ボクセルの頂点位置を考慮した条件に変更しました。
  - ワールド座標系でのZ座標計算を改良しました。

- **テクスチャ設定の最適化**
  - WebGL向けのテクスチャ設定を追加しました。
  - テクスチャの読み取り可能フラグ（isReadable）を有効にしました。

- **シーン設定の調整**
  - チャンクサイズを2から1に変更し、よりきめ細かい制御を可能にしました。
  - ボクセルサイズを8から4に変更し、描画パフォーマンスを向上させました。
  - ライトの色温度と角度を調整し、より自然な照明環境を構築しました。

## その他
- **プロジェクト構成の整理**
  - 全リリースノートファイル名を統一形式（`v0.x.x.md`）に変更しました。
  - リソースファイルの命名規則を改善しました。

## スクリプト実装概要

### 新規追加構造体・機能

#### `VoxelFaceTextureInfo` 構造体
- **面テクスチャ情報管理**: ボクセルの各面のテクスチャ情報を詳細に管理
- **主要フィールド**:
  - `faceNormal`: 面の法線ベクトル
  - `uvBase`, `uvSize`: UV座標の基点とサイズ
  - `sourceTexture`: 使用するテクスチャ
  - `isExposed`: 面の露出状態

### 変更されたスクリプト

#### `VoxelChunk.cs`
- **テクスチャ抽出機能の追加**:
  - `GetVoxelFaceTextureInfo()`: 指定面のテクスチャ情報取得
  - `GetAllVoxelFaceTextureInfo()`: 全面のテクスチャ情報取得
  - テクスチャ抽出の有効/無効設定と解像度設定を追加

- **初期化メソッドの拡張**:
  - テクスチャパラメータを含む新しい`Initialize()`オーバーロードを追加
  - テクスチャ設定の自動反映機能を実装

- **アイテムドロップ機能の改良**:
  - `DropItem()`メソッドにボクセル座標パラメータを追加
  - より詳細な位置情報を基にしたアイテム生成

#### `BaseCubePlacer.cs`
- **テクスチャ連携の強化**:
  - VoxelChunkの初期化時にテクスチャ情報を渡すように変更
  - テクスチャ1とテクスチャ2の両方をサポート

#### `CubeSideScrollerPlacer.cs`
- **境界判定ロジックの改善**:
  - ボクセルの頂点位置を考慮したより正確な境界チェック
  - Z軸制約の計算精度を向上させました

### 物理マテリアル

#### `PlayerPhysics.physicMaterial`
- 静的摩擦: 0、動的摩擦: 0
- プレイヤーの滑らかな移動を実現

#### `VoxelPhysics.physicMaterial` 
- 静的摩擦: 0.5、動的摩擦: 0.7
- ボクセル破壊アイテムの適切な物理挙動を実現
