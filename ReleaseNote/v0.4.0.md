# Release Note v0.4.0

## 新機能

- **Minecart機能の追加**: プレイヤーが採掘した資源を地上に運搬するためのトロッコシステムを実装。プレイヤーのインベントリがいっぱいになると自動的にアイテムをトロッコに移し、トロッコがいっぱいになると地上に送出されます。
- **Dynamiteツールの導入**: 新しい採掘ツールとしてダイナマイトを追加。投擲して爆発させ、周囲のブロックを掘削できます。投射距離や角度を調整可能なパラメータを備えています。
- **入力システムの拡張**: メイン採掘 (MainMine) とサブ採掘 (SubMine) のアクションを追加。また、マウス位置 (MousePosition) のトラッキングを導入し、ツールの使用を改善しました。

## 変更点

- **アニメーション調整**: `MineLeft.anim` の回転値を変更し、採掘アニメーションの動きを改善 (z軸の回転を-45度から-90度に調整)。
- **シーン更新**: `MiningScene.unity` でオブジェクトの親子関係やコンポーネントを変更。Pickaxeオブジェクトを削除し、Diggerプレハブを追加。
- **掘削システムの改善**: `Digger.cs` でダメージパラメータを追加し、掘削処理をより柔軟に。`Dig` メソッドに `damagePerHit` を渡すように変更。
- **カメラコントローラーの最適化**: `CameraFollowController.cs` のGizmos描画を削除し、エディタパフォーマンスを向上。

## その他

- **レイヤー変更**: `Minecart.prefab` のレイヤーを0から6 (Minecart) に変更し、衝突判定を改善。
- **デバッグ機能追加**: `DynamiteProjectile.cs` にGizmos描画機能を追加し、掘削モジュールのサイズを可視化。
- **プレハブ作成**: `MainDigger.prefab` と `DynamiteProjectile.prefab` を新規作成し、システムのモジュール化を強化。

## スクリプト実装概要

### `Assets/Scripts/Minecart/Minecart.cs`
- トロッコ単体の状態とデータを管理。移動コンポーネント、積載資源、地上送出クールダウンを扱う。

### `Assets/Scripts/Mining/Tools/Dynamite.cs`
- ダイナマイトツールのScriptableObject。投射力や上方力を設定可能。

### `Assets/Scripts/Mining/Tools/MiningTool.cs`
- 採掘ツールの基底クラス。ツールプレハブの生成とMiningToolBehaviourのインスタンス化を担当。

### `Assets/Scripts/Mining/Runtime/Behaviours/DynamiteToolBehaviour.cs`
- ダイナマイトの動作を制御。投擲軌道の計算と爆発による掘削を実行。

### `Assets/Scripts/Mining/Tools/DynamiteProjectile.cs`
- ダイナマイトの投射体スクリプト。衝突検知と爆発処理、Gizmos描画を担当。

### `Assets/Scripts/Mining/Digger.cs`
- 掘削処理の中心クラス。ダメージ適用とブロック破壊を管理。

### `Assets/Scripts/Camera/CameraFollowController.cs`
- カメラの追従制御。プレイヤーの移動に合わせてカメラを調整。
