# Release Note v0.5.0

## 新機能
- **StorageManagerクラスの追加**: 地上の貯蔵庫を管理する新しいクラスを導入。トロッコからリソースを受け取り、総量を保持する機能を追加。
- **MinecartState enumの導入**: Minecartクラスに状態管理用のenumを追加（Following, GoingToGround, Unloading）。これにより、トロッコの動作をより明確に制御可能。
- **タイトル画像の追加**: Resources/Titleフォルダに新しいタイトル画像を追加。
- **MinecartManagerの機能拡張**: トロッコの移動設定（groundStationPosition, followMoveSpeed, groundMoveSpeed, unloadTime）を追加し、地上への移動と荷降ろし処理を改善。
- **ChunkManagerクラスの追加**: 地形の動的生成とチャンク管理を行う新しいクラスを導入。プレイヤーの移動に応じたチャンクの生成と破棄を管理。
- **BlockDataアセットの拡張**: StoneDefault, TerrainDataManager, Undergroundなどの新しいBlockDataアセットを追加。generationWeightプロパティを導入。
- **新しいテクスチャの追加**: block_tsuchi.pngテクスチャをResourcesフォルダに追加。
- **Editor拡張の追加**: BiomeDataCustomEditor.csとBlockDistributionDrawer.csを追加し、バイオームデータのインスペクター表示を改善。
- **MinecartPlayerInteractionSystemの追加**: プレイヤーとトロッコのインタラクションを管理する新しいシステムをMiningSceneに追加。
- **BlockGeneratorの拡張**: GetBlockDataForPositionメソッドを追加し、論理座標に基づいたブロック生成を可能に。
- **シェーダーの追加**: AlwaysVisibleUnlit.shaderとUnlitBlock.shaderを追加し、カスタムUnlitマテリアルをサポート。
- **新しいテクスチャの追加**: block_ishi_painted.pngテクスチャを追加。
- **Materialsフォルダの作成**: Resources/Materialsフォルダを作成し、マテリアルを整理。
- **UniTaskの導入**: UniTaskライブラリをGitリポジトリから依存関係として追加し、非同期処理をサポート。

## 変更点
- **MinecartMovementの移動ロジック修正**: 移動ロジックをVector3.LerpからVector3.MoveTowardsに変更し、より安定した移動を実現。moveSpeedフィールドをprivateからpublicに変更。
- **StorageManagerのメソッド更新**: シングルトンインスタンス取得メソッドをFindObjectOfTypeからFindFirstObjectByTypeに変更。
- **MinecartManagerのリファクタリング**: 状態ベースの処理に変更し、旧式のフラグ（isGoingToGround）をMinecartStateに置き換え。不要なフィールド（cartcooltime, DeltaTime）を削除。
- **フォルダ構造の整理**: Assets/Scripts/Mining/RuntimeをAssets/ScriptableObjectsにリネーム。関連するBlockDataとToolsフォルダも移動。
- **MinecartMaterialのシェーダー更新**: シェーダーGUIDを更新し、disabledShaderPassesを調整。
- **MiningSceneのプロパティ追加**: groundStationPosition, followMoveSpeed, groundMoveSpeed, unloadTimeなどの新しいプロパティを追加。
- **README.mdの削除**: Assets/Scripts/Minecart/README.mdを削除。
- **変数名の統一**: Terrain関連スクリプト全体で変数名を統一（voxelSize -> voxelsPerBlock, chunkSize -> voxelsPerBlock, voxelSize -> voxelWorldSize）。ボクセルサイズの計算を統一。
- **TerrainManagerの設定更新**: worldSizeInChunks -> initialChunkCount, chunkSizeInBlocks -> blocksPerChunk, voxelSize -> voxelsPerBlockに変更。
- **BlockManagerの改善**: CreateBlockメソッドの引数型を修正、DestroyImmediateの条件分岐を追加（エディタ/プレイモード対応）。
- **BlockItemDropperの拡張**: ドロップアイテムにresourceTypeを設定する機能を追加。
- **デバッグコードのコメントアウト**: MinecartManagerの初期リソース追加コードをコメントアウト。
- **BlockDistributionDrawerの改善**: 描画範囲を0-10から0-1に変更し、カーブフィールドの表示を改善。
- **Biomeアセットの更新**: 1_Surface Layerと2_Shallow Sedimentary LayerのmaxHeight/minHeightを調整し、BlockDistributionを追加。
- **BlockItemDropperの質量設定**: アイテムドロップ時に密度に基づいた質量を設定。
- **BlockDataの拡張**: densityプロパティを追加（Stone: 2500, Soil: 1300）。
- **マテリアルのシェーダー変更**: IronMaterial, MinecartMaterial, StickMaterialのシェーダーをCustom/UnlitBlockに変更。
- **テクスチャGUIDの更新**: SoilとStoneのテクスチャを新しいものに更新。
- **MiningModuleの値調整**: DynamiteMiningModuleのexplosionForceを10から250に、PickaxeMiningModuleのminingForceを5から75に変更。
- **Pickaxe.prefabの調整**: 不要なプロパティを削除し、スケールと位置を調整。
- **MiningSceneの設定変更**: PlayerControllerのRigidbody質量を3から45に、Transform設定を調整、CapsuleColliderの方向を変更、MeshRendererのマテリアルを更新。
- **掘削処理の非同期化**: DiggerおよびBlockクラスの掘削処理をコルーチンからUniTaskベースの非同期メソッドに変更し、パフォーマンスを向上。
- **アイテム転送処理の非同期化**: MinecartPlayerInteractionSystemのアイテム転送処理をコルーチンからUniTaskに変更し、アニメーションと待機処理を改善。
- **アイテム管理とブロック生成処理の非同期化**: DroppedItemManager、PlayerController、ChunkManagerの処理をUniTaskに変更し、キャンセレーショントークンを使用してリソース管理を改善。

## その他
- マージコミット: feature/StorageSystemブランチとnun_partブランチの変更を統合。
- 全体として、トロッコシステムの安定性と機能性を向上させるためのリファクタリングが中心。Terrainシステムの変数名統一によりコードの保守性が向上。

## スクリプト実装概要

### `StorageManager.cs`
- 新規作成: 地上の貯蔵庫を管理するシングルトンクラス。
- リソースの追加、取得、貯蔵量の管理機能を実装。
- Awake()で全リソースタイプを初期化し、DontDestroyOnLoadを設定。

### `Minecart.cs`
- MinecartState enumを追加し、stateフィールドを導入。
- isGoingToGroundフラグをstateに置き換え。

### `MinecartManager.cs`
- 移動設定フィールドを追加（groundStationPosition, followMoveSpeed, groundMoveSpeed, unloadTime）。
- SendCartToHome()で状態をGoingToGroundに変更し、移動速度を設定。
- UpdateMinecartPositions()で状態に基づく処理に変更。
- 地上到着時の処理をswitch文で状態管理。

### `MinecartMovement.cs`
- moveSpeedをpublicに変更。
- 移動ロジックをMoveTowardsに変更。

### `MiningScene.unity`
- MinecartManagerコンポーネントに新しいプロパティを追加。

### `MinecartMaterial.mat`
- シェーダーGUIDを更新し、disabledShaderPassesを空に設定。

### `ChunkManager.cs`
- 新規作成: 地形の動的生成とチャンク管理を担当。
- プレイヤーの移動に応じたチャンクの生成と破棄を管理。
- ProcessBlockGenerationQueueコルーチンでブロック生成を非同期処理。

### `BlockManager.cs`
- CreateBlockメソッドの引数名を修正（voxelSize -> voxelsPerBlock）。
- CreateBlockMaterialメソッドの引数型を修正（global::BlockData -> BlockData）。
- DestroyImmediateの条件分岐を追加（エディタ/プレイモード対応）。

### `TerrainManager.cs`
- 設定変数名を変更（worldSizeInChunks -> initialChunkCount, chunkSizeInBlocks -> blocksPerChunk, voxelSize -> voxelsPerBlock）。
- チャンク生成ロジックを更新。

### `VoxelManager.cs`
- RegisterVoxelsFromPatternメソッドの引数名を修正（voxelSize -> voxelsPerBlock）。
- CalculateWorldPositionメソッドの計算を統一。

### `Block.cs`
- プロパティ名を変更（ChunkSize -> VoxelsPerBlock, voxelSize -> voxelWorldSize）。
- Initializeメソッドの引数名を修正。
- DigVoxelsメソッドをUniTaskに変更。

### `BlockDiggingSystem.cs`
- 変数名を変更（chunkSize -> voxelsPerBlock）。
- TakeDamageメソッドの計算を更新。
- DigVoxelsメソッドをUniTaskに変更し、yield return nullをawait UniTask.Yield()に置き換え。

### `BlockItemDropper.cs`
- 変数名を変更（voxelSize -> voxelWorldSize, chunkSize -> voxelsPerBlock）。
- DropItemメソッドにresourceType設定を追加。
- 質量設定を追加（volume * density）。

### `BlockMeshGenerator.cs`
- 変数名を変更（chunkSize -> voxelsPerBlock）。
- GenerateMeshメソッドの計算を更新。

### `VoxelTextureExtractor.cs`
- 変数名を変更（chunkSize -> voxelsPerBlock）。
- GetVoxelFaceTextureInfoメソッドの計算を更新。
- ApplyDefaultMaterialメソッドでCustom/UnlitBlockを使用。

### `BiomeDataCustomEditor.cs`
- 新規作成: BiomeDataのインスペクター表示をカスタマイズ。
- BlockDistributionDrawerを使用してavailableBlocksを表示。

### `BlockDistributionDrawer.cs`
- 新規作成: BlockDistributionのプロパティドロワーを実装。
- 描画範囲を0-1に設定し、AnimationCurveフィールドを表示。

### `MinecartPlayerInteractionSystem.cs`
- 新規作成: プレイヤーとトロッコのインタラクションを管理。
- トロッコの検出、アイテム転送、移動制御を担当。
- TransferItemsToMinecartメソッドをUniTaskに変更。
- AnimateItemTransferメソッドをUniTaskに変更。
- MoveItemAsyncメソッドをUniTaskに変更し、await UniTask.Yield()を使用。

### `BlockGenerator.cs`
- GetBlockDataForPositionメソッドを追加。
- 論理座標に基づいてBlockDataを取得し、重み付きランダム選択を実装。

### `BlockData.cs`
- densityプロパティを追加（物理質量計算用）。

### `AlwaysVisibleUnlit.shader`
- 新規作成: 常に表示されるUnlitシェーダー。
- ZTest Alwaysを使用し、透明度クリッピングをサポート。

### `UnlitBlock.shader`
- 新規作成: ブロック用のUnlitシェーダー。
- AlphaTestキューを使用し、テクスチャと色をサポート。

### `Packages/manifest.json`
- UniTask依存関係を追加（Git URLから）。

### `Digger.cs` (更新)
- 掘削処理をUniTaskに変更し、block.DigVoxels().Forget()を使用。

### `PlayerController.cs` (更新)
- PickupRetryAsyncメソッドをUniTaskに変更し、CancellationTokenを使用してキャンセル処理を改善。
- OnDisableでCancellationTokenSourceを適切に破棄。

### `DroppedItemManager.cs` (更新)
- ProcessWakeUpQueueAsyncメソッドをUniTaskに変更し、await UniTask.Delay()を使用。

### `ChunkManager.cs` (更新)
- ProcessBlockGenerationQueueメソッドをUniTaskに変更し、CancellationTokenを使用してキャンセル処理を改善。
- OnDestroyでCancellationTokenSourceを適切に破棄。
- ClearChunksメソッドでコルーチンを停止する代わりにCancellationTokenを使用。
