# Release Note v0.3.0

## 新機能

### 動的テレイン生成システム
- プレイヤーの位置に基づく動的なチャンク生成システムを実装
- プレイヤー周囲の指定範囲内のチャンクのみを生成・描画するように最適化
- 距離に応じたブロック生成優先度システム

### ドロップアイテム物理最適化システム
- アイテムの自動スリープ機能を実装（一定時間静止したアイテムを物理演算から除外）
- 掘削時のアイテム起床システム（掘削範囲内のアイテムを段階的に起床）
- フレームレート安定化のための最適化パラメータ調整

### プレイヤー移動システムの改良
- 移動に慣性システムを追加（加速・減速の滑らかな変化）
- サイドスクローラーモード時の落下制御を改善
- 無入力時の緩やかな落下機能を追加

## 変更点

### パフォーマンス最適化
- 掘削処理を非同期化（コルーチンベース）でフレーム分散処理
- ブロック生成を1フレームあたり16個に制限
- VoxelPrefabにRigidbodyとDroppedItemコンポーネントを統合

### アーキテクチャ改善
- チャンクとブロックの親子関係を明確化
- `BlockData`クラスの`ResourceType`冗長性を削除
- ブロック生成時の親Transform指定を改良

### UI改善
- ボクセル数表示UIを追加
- プレイヤーの深度表示システムを継続

### 設定調整
- ワールドサイズを3x1から2x5チャンクに変更
- チャンクサイズを10x10から5x5ブロックに最適化
- 描画距離を2チャンク範囲に設定

## その他

### バグ修正
- サイドスクローラーモードでの掘削範囲最適化
- 重複するGameObjectの削除（BlockManagerの非アクティブ化）

### 開発者向け改善
- デバッグログの詳細化
- パフォーマンス監視パラメータの調整

## スクリプト実装概要

### `TerrainManager.cs`
- 動的チャンク生成システムの実装
- プレイヤー位置ベースのチャンク管理
- 距離ベースのブロック生成優先度制御
- 非同期ブロック生成キューシステム

### `BlockManager.cs`
- ブロック生成時の親Transform指定機能追加
- `ResourceType`パラメータの明示的指定

### `Chunk.cs`
- 新規作成：チャンクデータ管理クラス
- チャンク位置の初期化機能

### `Block.cs`
- 掘削処理の非同期化（IEnumeratorベース）
- VoxelManagerとの統合による冗長性削除
- サイドスクローラーモード対応の掘削最適化

### `DroppedItemManager.cs`
- アイテムスリープ・起床システムの実装
- フレームレート制御のための段階的処理
- 物理演算最適化パラメータの調整

### `PlayerController.cs`
- 慣性ベースの移動システム実装
- 加速・減速パラメータの追加
- サイドスクローラーモード時の落下制御改良

### `DroppedItem.cs`
- Rigidbodyコンポーネントとの統合
- 物理状態管理の改良
